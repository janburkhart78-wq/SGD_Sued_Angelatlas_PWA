# SGD Süd Angelatlas auf iPhone/iPad testen

Diese Variante ist keine App-Store-App, sondern eine iOS-taugliche Web-App/PWA.

## Installation auf iPhone/iPad

1. Die Web-App über Safari öffnen.
2. In Safari auf „Teilen“ tippen.
3. „Zum Home-Bildschirm“ wählen.
4. Namen bestätigen, z. B. „Angelatlas“.
5. Danach über das neue Symbol starten.

## Wichtig

- iOS installiert PWAs sauber nur aus Safari.
- Für Service-Worker/Cache sollte die App über HTTPS erreichbar sein.
- Karten-Luftbilder und Online-Karten brauchen weiterhin Internet.
- Gespeicherte Stellen und Fangmeldungen liegen lokal auf dem jeweiligen Gerät.
- Die App ersetzt keine Erlaubnisscheine, Beschilderung oder amtliche Regeln.

## Schnelltest im gleichen WLAN

Für einen schnellen Test kann die App auch über einen lokalen Webserver geöffnet werden. Für dauerhaftes Testen mit iPhones ist HTTPS-Hosting besser, z. B. GitHub Pages oder ein kleiner Webhost.
